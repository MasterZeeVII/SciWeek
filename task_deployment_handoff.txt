HISTORICAL DATA MIGRATION (IN PROGRESS)
======================================================================
Goal: import 4 past years of SCIWEEK tournament data (originally run on
Toornament.com, before this Django app existed) as historical season
records on the new site.

Source Toornament URLs (JS-rendered SPA -- plain WebFetch only returns an
empty shell, need an actual browser / rendering tool to scrape):
  2564 BE (2021 CE): https://play.toornament.com/en_GB/tournaments/4875144952448212992/
  2565 BE (2022 CE): https://play.toornament.com/en_GB/tournaments/5920154387402342400/
  2566 BE (2023 CE): https://play.toornament.com/en_GB/tournaments/7007340032918134784/
  2567 BE (2024 CE): https://play.toornament.com/en_GB/tournaments/8083614506537877504/
  (Thai Buddhist Era year - 543 = Gregorian year)

User wants: full bracket + match results, AND participating schools/teams list.

STEP 1 DONE -- participants only:
  User manually extracted participant lists from Toornament into
  participants.txt (repo root; raw, inconsistent formatting across years --
  mixed "รร."/"ร.ร." prefixes, team counts encoded as "ทีมที่ N" or "(N)"
  suffixes, one real typo "นครสวรรรค์"->"นครสวรรค์" that also exists as a
  duplicate row in the live DB).

  Parsed/cleaned/generated via scripts (not kept in repo, were scratch):
  logic lived in a one-off Python parser that:
    - strips ม.ต้น/ม.ปลาย prefix -> JUNIOR/SENIOR division
    - normalizes รร./ร.ร. -> ร.ร. (ศกร. left alone, different institution type)
    - extracts trailing "ทีมที่ N" / "(N)" as team_number, NOT part of name
      (but "(บ้านหนองไม้แดง)" style parens with real text are correctly left
      alone -- that's part of the actual school name, confirmed by user)
    - fixed the นครสวรรรค์ typo
    - confirmed with user: ร.ร.สตรีนครสวรรค์ and ร.ร.นครสวรรค์ are genuinely
      different schools (not a typo despite high string similarity)
    - confirmed with user: ร.ร.สวนกุหลาบวิทยาลัยฯ (2564/2565) and
      ร.ร.สวนกุหลาบวิทยาลัย (จิรประวัติ) (2566) are genuinely different
      campuses, kept as separate schools

  Result: prepdata/import_participants.sql -- inserts 40 unique schools,
  4 tournaments (years 2021/2022/2023/2024, name "NSRU E-Sport SCIWEEK",
  is_active=0 so it won't disturb the current live season), 8 divisions
  (JUNIOR+SENIOR per year), 98 team rows (school+division+team_number).
  No team_members (no player names in source data). No matches/games yet.

  Import is written with SET FOREIGN_KEY_CHECKS=0/1 wrapping and resolves
  all FKs by name/year via subqueries + session vars (@tid/@jid/@sid), not
  hardcoded IDs -- safe regardless of what auto-increment state the DB is
  actually in. Schools insert is idempotent (skips existing names); the
  tournaments/divisions/teams inserts are NOT idempotent -- check
  `SELECT year FROM tournaments;` before re-running, or it'll fail on the
  unique year constraint.

  Run via CLI (not phpMyAdmin, see lesson above):
    mysql -u root -p sciweek < prepdata/import_participants.sql
  Then verify: SELECT COUNT(*) FROM schools;  -- should be 40
  (User pasted a phpMyAdmin table view showing only 25 rows -- that's just
  phpMyAdmin's default page size, not the real count. Use SELECT COUNT(*).)
